# 设计：自由英语对话（三个阶段都已实现：[第一阶段](自由英语对话解析.md)、[录音评判与查询](React改版与英语录音评判解析.md)、[复习测验](英语复习测验解析.md)）

把口语陪练从“选场景、角色扮演、跟读固定句子”改成**自由英文对话**：

- 想聊什么就聊什么；
- 你说的话有问题，就在你那句话下面指出来；
- 陪练说的单词、句子看不懂，可以看标注，点一下就有解释；
- 出过错的句子和不认识的词句**自动入库**；
- 下次按遗忘规律**生成测试题**，到期的词还会被陪练在对话里自然用到。

## 和当前版本比

| | 场景版（`practice` 分支，未提交） | 自由对话版 |
|---|---|---|
| 话题 | 5 个固定场景，陪练扮演角色 | 不限，可选填一个话题开头；陪练是聊天伙伴，按你的水平说话 |
| 问题指出 | 批注列表放在卡片里 | **批注贴在你那句话下面**，同时记进错题本 |
| 看不懂 | 没有 | 超出水平的词**自动加下划线**并标注；**点任何词或句子**都能看解释；你问“这个词什么意思”也会被记下 |
| 入库 | 只存练习记录 | 生词本、错题本，带复习进度 |
| 下次 | 规划 agent 给出“下一课” | **测试题**（选择、拼写、听写、改错、翻译）+ 到期的词融进下次对话 |
| 跟读 | 只能读固定的热身句 | 任何一句陪练的话、任何一个生词都能跟读 |

**沿用**（约七成代码不用重写）：WebSocket 练习模式、英语识别和英语音色、英文分句、评估 agent 的“同时跑、不挡回答”、结束后的报告任务、跟读的逐词对齐、练习记录表、多 agent 框架和花费记账。

**去掉**：固定场景、角色提示、规划 agent、固定热身句。

## agent 分工

| agent | 什么时候 | 输入 | 输出 | 每次预算 |
|---|---|---|---|---|
| `tutor` 陪练 | 每句话，前台 | 你的水平、可选话题、最近 12 条对话、2～3 个到期生词 | 英语回答，最多三句，以问题结尾；你说中文时先用一句中文帮你，再回到英语 | 和平时对话一样，不单独限额 |
| `corrector` 纠错 | 你每说一句，后台 | 你这句 + 陪练上一句 | JSON：最重要的一处问题（原句、改法、更地道的说法、中文说明）；你问过意思的词（如“what does *budget* mean”“budget 是什么意思”） | 0.005 元 |
| `annotator` 标注 | 陪练每说一句，后台 | 陪练这句 + 你的水平 | JSON：超出水平的词或短语（音标、中文义）+ 整句中文翻译 | 0.005 元 |
| `explainer` 解释 | 你点一个没有标注的词或句子时 | 选中的内容 + 所在句子 | 中文解释：词义（结合这句话）、音标、例句；句子给翻译和结构 | 0.005 元 |
| `quiz_maker` 出题 | 你点“开始测验”，后台任务 | 到期的条目 | JSON 题目：选择题的干扰项、填空题的挖空句 | 0.02 元 |
| `grader` 判分 | 交卷时，只判开放题 | 题目、标准答案、你的答案 | 对/错 + 一句中文点评 | 0.01 元 |
| `practice_report` 报告 | 结束练习，后台任务 | 对话、批注、新入库的条目 | 简短总结：说得好的、主要问题、本次新词 | 0.03 元 |

所有后台 agent 照旧只读、不写。入库由服务器代码根据 agent 输出完成，agent 本身没有写工具。

## 标注和“看不懂”怎么记

- **自动标注**：只标超出你水平的词（水平在卡片上选：初级、中级、高级），每句最多 5 个，避免满屏下划线。整句翻译默认折叠，点“翻译”才显示，不剧透。
- **点词**：点陪练话里的任何词，弹出解释。已经标注过的词直接显示，不调模型。弹窗里有“跟读”和“已经会了”。
- **点句子**：每条陪练气泡右下角有“翻译”“跟读”“解释这句”。
- **什么算“不认识”**（入生词本的条件）：
  - 你点开看过解释的词或句子；
  - 你在对话里问过意思的词（纠错 agent 抽出来）。
- 只是被自动标注、你没点的词**不入库**，否则生词本很快被你其实认识的词塞满。弹窗里点“已经会了”的词，以后不再标注。
- **错题**：纠错 agent 指出的每个问题都入错题本：原句、改法、说明、出现在哪次对话。

## 学习库（每用户，放在 `agent.db`）

```
english_items
  id, kind            word | phrase | sentence | mistake
  text                词、短语、句子；错题是你说的原句
  meaning             中文义或翻译；错题是改法
  phonetic, note      音标；用法说明或错因
  context             出现时的那句话（出题时用来挖空）
  session_id, created_at, seen_count
  box, due_at         间隔复习进度（见下）
  tested, correct, mastered, known
  唯一键：(kind, 小写 text)，重复出现只加 seen_count、更新语境
english_quizzes
  id, created_at, questions_json, answers_json, score, finished_at
```

### 间隔复习

采用 Leitner 盒子，规则简单、可解释：

| 盒子 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 隔几天再考 | 当天 | 1 | 2 | 4 | 7 | 15 |

- 答对进下一个盒子；答错回到 1 号盒，明天再考。
- 在 5 号盒再答对，就算“掌握”，不再出题。
- 新入库的条目放在 0 号盒，下次就能考到。

## 测试题

点“开始测验（今天到期 N 个）”，一次最多 10 题。优先出错题和逾期最久的。

| 条目 | 题型 | 判分 |
|---|---|---|
| 词、短语 | 看英文选中文义（4 选 1，干扰项由出题 agent 生成） | 本机 |
| 词、短语 | 看中文和语境写英文 | 本机：忽略大小写、标点；有拼写误差时交给判分 agent |
| 词、短语 | 语境填空：用当时那句话挖掉这个词 | 本机 |
| 句子 | 听写：英语音色读一遍，你打出来 | 本机：复用跟读的逐词对齐，读对 90% 以上算对 |
| 句子 | 翻译成中文 | 判分 agent |
| 错题 | 改错：给出你当时说的原句，写出正确说法 | 判分 agent，对照改法 |

- 交卷后逐题显示对错、标准答案和点评；每题都可以点“跟读”。
- 结果更新每个条目的盒子。
- **对话里复习**：开始对话时，取 2～3 个到期的词放进陪练提示，让它自然用到。你在对话里正确用出这些词，纠错 agent 会标记，算一次答对。这一条放在第三阶段，先做书面测验。
- 口头作答（用说的回答测验）放到以后，等新麦克风到了一起测。

## 页面

- “口语陪练”改名为“**英语对话**”：水平（初级/中级/高级）、可选话题、开始/结束、“开始测验（今天到期 N 个）”。
- 对话就在页面原来的对话区里进行：
  - 你的气泡下面显示批注（黄色）；
  - 陪练气泡里，超出水平的词加下划线，点开有解释；
  - 每条陪练气泡有“翻译”“跟读”“解释这句”。
- 新增“**生词本 / 错题本**”：
  - 按类型筛选；
  - 显示复习进度（盒子、下次考的日期）；
  - 可以删除、标为已掌握、跟读。
- 测验在卡片里一题一题做，交卷后显示结果。

## 花费估算（deepseek-flash 高峰价）

- 对话中每一轮 3 次调用（陪练、纠错、标注），20 分钟约 40 轮，约 **0.15 元**（原来约 0.1 元）。
- 点开解释，每次约 0.001 元；已标注的词不花钱。
- 一次 10 题测验约 **0.02 元**（出题一次，开放题判分一次）。
- 后台 agent 都计入每天 2 元的上限，到上限只是没有标注和批注，对话照常。

## 分三个阶段做

| 阶段 | 内容 | 能看到的效果 |
|---|---|---|
| 1 | 去掉场景改成自由对话；选水平和话题；批注贴在你那句话下面；错题入库；错题本页面 | 自由聊天，问题当场指出，错题能翻看 |
| 2 | 标注 agent；点词或句子解释；问意思的词入库；生词本；任意句子跟读 | 看不懂的词句能查，查过的自动进生词本 |
| 3 | 间隔复习；出题和判分；测验页面；到期的词融进下次对话 | 下次打开先做测验，对话里复习 |

每个阶段照惯例：测试，浏览器实测（用录好的英语音频；真麦克风等新麦克风），带流程图和代码讲解的解析文档。

## 要你定的

1. **当前场景版怎么处理？** 建议在 `practice` 分支上直接改成自由对话版，场景版不合并进 main。另一个选择是先提交场景版，作为历史留在分支上，再在上面改。
2. **自动标注要不要？** 建议要：每轮多一次调用，约增加 0.04 元/20 分钟。不要的话只保留“点了才解释”。
3. **水平怎么定？** 建议你在卡片上选，陪练和标注照着调整。自动判断留到以后。
4. **测验先做书面的**，口头作答以后做，可以吗？

## 测试计划

- 纠错 JSON：问题和“问过意思的词”都能解析；格式不对就不入库。
- 入库：同一个词重复出现只计数；“已经会了”的词不再标注；只被自动标注、没点过的不入库。
- 间隔复习：答对升盒、答错回 1 号盒、5 号盒答对算掌握；到期筛选和优先级。
- 出题：每种题型的结构；选择题恰好 4 个选项、答案在其中；填空题确实挖掉了目标词。
- 判分：本机判分（大小写、标点、听写 90%）；开放题交给判分 agent；结果正确更新盒子。
- WebSocket：批注带上对应那句话的编号，页面能贴到正确的气泡下；到期的词进了陪练提示；回到平时助手时没有练习内容（沿用现有测试）。
- 前端：下划线、点词弹窗、翻译折叠、生词本筛选、测验一题一题作答和结果。
